## 选择产品

| 产品     | 适用任务                       | 计费方式                 |
| -------- | ------------------------------ | ------------------------ |
| 动态住宅 | 地区测试、独立的公开数据请求   | 流量包（GB，30 天有效）  |
| 静态住宅 | 需要固定出口的长期任务         | 按 IP、地区与租期        |
| 静态原生 | 对网络身份有特定要求的任务     | 按 IP、地区与租期        |

不确定选哪种？控制台的**选购顾问**会根据你的任务问几个问题并给出建议。
