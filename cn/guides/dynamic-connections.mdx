---
title: 动态连接
description: 为动态住宅子账号生成连接信息。
---

动态住宅的连接信息在控制台中按需生成，之后由你的程序直接连接代理入口。

## 前提条件

**我的产品 → 动态住宅**页面会显示开通进度。满足以下全部条件后即可生成连接信息：

- 已为你分配动态子账号（首次购买流量时自动创建）；
- 子账号有可用流量；
- 子账号在网络服务方处于启用状态。

## 生成连接信息

<Steps>
  <Step title="选择子账号">
    打开**我的产品 → 动态住宅**，在**连接信息**中选择子账号。列表只显示仍有流量的启用子账号。
  </Step>
  <Step title="选择地区">
    保持**不限地区**，或选择国家。可用时还能细化到州/省和城市。
  </Step>
  <Step title="选择 IP 模式">
    - **轮换**：不同请求之间出口可能变化。
    - **粘性会话**：在 1–120 分钟内保持同一出口。
  </Step>
  <Step title="选择协议">
    **HTTP** 或 **SOCKS5**。HTTP 代理同样可以访问 HTTPS 目标。
  </Step>
  <Step title="生成并复制">
    控制台显示主机、HTTP 端口、SOCKS5 端口、用户名和密码，以及可直接运行的 cURL、Python、Node.js、Go 和 Java 示例。
  </Step>
</Steps>

生成的连接信息只对应你当时选择的设置。更改地区、IP 模式或协议后，请重新生成。

<Warning>
  连接信息只在你隐藏、刷新页面或切换子账号之前显示。请直接复制到你的密钥管理工具或服务器环境变量中。
</Warning>

## SOCKS5 与 DNS

使用 `socks5h://` 时，目标域名在代理端解析，与 HTTP 代理一致。普通的 `socks5://` 会在你自己的机器上解析域名。

## 用量

**我的产品 → 动态住宅 → 用量明细**显示剩余流量、流量包到期时间，以及每个子账号最近 7 天或 30 天的每日用量（日期按 UTC+8），并可导出 CSV。代理流量不经过 ipcrazy，因此不提供逐条请求日志。
