---
title: 静态 IP
description: 静态住宅与静态原生 IP 的连接信息、续费和自动续费。
---

已交付的静态住宅和静态原生 IP 分别列在**我的产品 → 静态住宅**和**我的产品 → 静态原生**。每个列表都可按状态筛选，每一行显示地区、到期时间和续费设置。

## 连接信息

在 IP 上点击**连接信息**，可查看主机、端口、协议、用户名和密码，并提供两种可复制的格式：

```text
http://USERNAME:PASSWORD@HOST:PORT
HOST:PORT:USERNAME:PASSWORD
```

连接信息只在你点击时实时读取，不会保存在 ipcrazy 或浏览器中，刷新页面即隐藏。你的程序直接连接代理地址，无需经过 ipcrazy 中转。

## 续费

勾选一个或多个 IP，点击**续费所选**，选择租期并确认。续费从钱包余额支付。

- 续费从当前到期时间顺延，提前续费不会损失时长。
- IP 与连接信息保持不变。
- 一笔续费订单只能包含同一种产品的 IP。

## 自动续费

在 IP 上打开**续费设置**，打开**开启自动续费**开关并选择续费周期。控制台会显示每次续费的价格，点击**确认价格并保存**。

- 在 IP 到期前 24 小时内，从钱包余额自动续费。
- 每个 IP 单独生成续费订单，金额**不超过你确认的价格**。
- 单价上涨时不会扣费。列表会提示续费价格已变化，直到你在**续费设置**中重新确认价格。
- 余额不足时不会续费，请在**账户设置 → 通知偏好**中保持到期提醒开启。
- 到期前可随时为任一 IP 关闭自动续费。

<Note>
  自动续费未成功时，IP 会显示“上次自动续费未成功”。请在到期前手动续费以保留该 IP。
</Note>
