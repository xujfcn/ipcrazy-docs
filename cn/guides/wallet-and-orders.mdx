ipcrazy 上的所有购买都从钱包余额支付。价格、余额、订单与退款均以**美元**计。

## 充值

1. 在控制台打开**钱包与流水**，发起充值。
2. 在表单显示的范围内输入金额，或选择预设金额。
3. 选择支付方式。表单只列出当前已开启的方式，视可用情况可能包括 PayPal、USDT（TRC20）和支付宝。
4. 在跳转后的收银台完成支付。

只有支付网关确认到账后，余额才会入账，通常在一两分钟内完成。

<Tip>
  使用 USDT 时，请通过 TRC20 网络转入收银台显示的准确金额。使用支付宝时，用支付宝 App 扫描收银台的二维码。
</Tip>

## 余额与流水

**钱包与流水**显示可用余额、冻结金额，以及每一笔流水：充值、购买、续费和退款。

## 扣款与退款规则

- 下单时，订单金额先从余额中**冻结**。
- 交付成功后**扣除**冻结金额；交付失败时自动**退回**。
- 交付结果暂不明确时，冻结金额保持不变，由工作人员核实。不会重复扣款。
- 可用余额不足时不会下单，请先充值再重试。

## 订单进度

**我的订单**列出你的购买和续费订单，以及付款和交付状态：

| 交付状态 | 含义 |
| --- | --- |
| 等待审核 | 已付款并冻结金额，下单前需人工检查。审核未通过的订单全额退款。 |
| 采购中 / 交付中 | 正在下单和交付，页面会自动刷新。 |
| 已交付 | 可以使用。 |
| 部分交付 | 未交付部分的金额已退回钱包。 |
| 已取消 / 交付失败 | 金额已退回钱包。 |

交付后的处理规则见[售后政策](/cn/policies/after-sales)。
