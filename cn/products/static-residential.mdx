---
title: 静态住宅
description: 固定住宅（ISP）IP，适合长期运行的任务。
---

静态住宅代理在整个租期内提供固定的住宅出口，适合需要连续数天或数周保持一致连接环境的任务。

## 概览

| | |
| --- | --- |
| 计费 | 按 IP、地区与租期计价，数量越多可享阶梯价 |
| 租期 | 7 天或 30 天 |
| 交付 | 付款后按地区自动交付 |
| 续费 | 手动续费，或在已确认的价格上限内自动续费 |

## 购买

在控制台打开**选购产品 → 静态住宅**：

1. 选择一个或多个地区，每个地区会显示当前库存。
2. 为每个地区设置数量，并选择租期。
3. 核对美元总价后确认，订单从钱包余额支付。

单个 IP 的价格取决于地区、租期和数量阶梯。下单时会再次检查库存；部分 IP 未能交付时，对应金额自动退回钱包。

## 交付之后

已交付的 IP 显示在**我的产品 → 静态住宅**，包括地区、到期时间和状态。每个 IP 都有独立的连接信息与续费设置。详见[静态 IP](/cn/guides/static-ips)。

<Note>
  购买的是所选租期内的使用权，不是永久资源。如需保留同一 IP，请在到期前续费。
</Note>
