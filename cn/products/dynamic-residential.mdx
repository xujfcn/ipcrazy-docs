---
title: 动态住宅
description: 轮换或粘性住宅出口，按流量计费。
---

动态住宅代理通过你所选地区的住宅出口转发每个请求。相互独立的请求使用轮换模式；短流程需要在一段时间内保持同一出口时，使用粘性会话。

## 概览

| | |
| --- | --- |
| 计费 | 按 GB 购买流量包，每个流量包有固定有效期（目前为 30 天） |
| 协议 | HTTP（也可访问 HTTPS 目标）与 SOCKS5 |
| IP 模式 | 轮换，或粘性会话 1–120 分钟 |
| 地区 | 不限地区，或在可用时细化到国家、州/省与城市 |
| 用量 | 按子账号统计每日用量，可导出 CSV |

当前流量包与美元价格见[价格页](https://ipcrazy.com/zh/pricing)，以及控制台**选购产品 → 动态住宅**。

## 流量规则

- 购买流量包后，流量发放到你的动态子账号。首次购买时自动创建子账号。
- 持有多个流量包时，优先扣减最早到期的流量包。
- 只有未过期且未撤销的流量包计入可用流量。
- 子账号流量用完或流量包全部过期时会暂停，发放新流量后恢复。
- 用量数据来自网络服务方的核实数据，可能有短暂延迟。

<Note>
  粘性会话在你选择的时长内保持同一出口，但不保证永久固定 IP。需要固定 IP 时，请使用[静态住宅](/cn/products/static-residential)或[静态原生](/cn/products/static-native)。
</Note>

## 限制

- 暂不支持自助创建更多子账号，也不支持在子账号之间转移流量。
- 代理流量由你的程序直接发往代理入口，ipcrazy 没有逐条请求日志，只提供每日用量。
