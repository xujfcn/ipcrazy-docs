---
title: 静态原生
description: 固定原生 IP，适合对网络身份有特定要求的任务。
---

静态原生代理按地区与租期提供固定的原生 IP，用于需要特定网络身份的授权任务。

## 概览

| | |
| --- | --- |
| 计费 | 按 IP、地区与租期计价，数量越多可享阶梯价 |
| 租期 | 7、30 或 90 天 |
| 交付 | 付款后按地区自动交付 |
| 续费 | 手动续费，或在已确认的价格上限内自动续费 |

## 购买

在控制台打开**选购产品 → 静态原生**，选择地区、每个地区的数量和租期。订单以美元从钱包余额支付；未能交付的 IP 对应金额自动退回钱包。

静态原生的地区列表和价格独立于静态住宅。一笔续费订单只能包含同一种产品的 IP。

## 评估是否适用

请根据线路的实际规格，并在你自己有权访问的目标上测试来评估。ipcrazy 不承诺第三方匿名度评级或 IP 检测分数；这些结果仅供参考，不决定目标网站是否接受连接。

交付后，在**我的产品 → 静态原生**管理这些 IP。详见[静态 IP](/cn/guides/static-ips)。
